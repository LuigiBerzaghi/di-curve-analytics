# Contrato de dados do site

JSON gerados por `dicurve-publicar` a partir dos dados abertos em `data/abertos/`
(Banco Central do Brasil, licença ODbL). `latest.json` aponta para o último dia aprovado
nas verificações; ficam guardados os 20 dias mais recentes e a superfície de 120 pregões.

Carteira (`risk.json`) e balanço (`alm.json`) são **simulados**.

Fonte: Banco Central do Brasil, Negociação de Títulos Federais no Mercado Secundário e
SGS 4389 (CDI). Estes dados derivados estão sob a Open Database License (ODbL) 1.0.
