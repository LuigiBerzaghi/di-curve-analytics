# Dados do Tesouro Direto (prefixados)

`prefixados.csv` é um recorte da base **Taxas dos Títulos Ofertados pelo Tesouro Direto**,
publicada pela Secretaria do Tesouro Nacional no
[Tesouro Transparente](https://www.tesourotransparente.gov.br/ckan/dataset/df56aa42-484a-4a59-8184-7676580c81e3)
sob a [Licença Aberta para Bases de Dados (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/).

- Recorte: Tesouro Prefixado (LTN) e Tesouro Prefixado com Juros Semestrais (NTN-F), desde 01/01/2020.
- Formato original: separador `;`, decimal `,`, datas `dd/mm/aaaa`, taxas em % a.a.
- Atualizado pelo workflow `.github/workflows/tesouro.yml`.

Fonte: Tesouro Nacional, Tesouro Transparente. Este recorte e os dados derivados dele
publicados neste repositório também estão sob a ODbL.
